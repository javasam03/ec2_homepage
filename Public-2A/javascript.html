변수와 자료형

JavaScript에서는 데이터를 저장하기 위해 변수를 사용한다. 문자열, 숫자, 논리값 등 다양한 자료형을 다룰 수 있다.

🔁

조건문과 반복문

조건문은 상황에 따라 다른 코드를 실행하고, 반복문은 같은 작업을 여러 번 수행할 때 사용한다.

⚙️

함수

함수는 여러 명령문을 하나의 기능으로 묶어 재사용할 수 있게 해 준다.

JavaScript 주요 학습 내용

구분 학습 내용 설명
기초 문법 변수, 자료형, 연산자 JavaScript 코드 작성에 필요한 기본 문법을 학습한다.
제어문 if문, switch문, for문, while문 조건에 따라 코드를 실행하거나 반복 작업을 수행한다.
함수 함수 선언식, 함수 표현식, 화살표 함수 코드를 기능 단위로 묶어 재사용할 수 있다.
DOM 요소 선택, 내용 변경, 이벤트 처리 HTML 요소를 JavaScript로 제어하여 동적인 화면을 만든다.

  • 입력값을 받아 화면에 출력하기
